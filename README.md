# VCF Variant Filtering

A simple Python project for filtering genomic variants from VCF files based on quality metrics.

## Objectives

- Read a VCF file
- Filter variants using quality thresholds
- Generate a filtered VCF file
- Practice Python applied to genomic data analysis

## Project structure

- `data/` – example VCF files
- `src/` – Python scripts

## Status

Educational project under development.
